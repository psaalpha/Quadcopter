# 后续演进路线

## 已完成的工程基线

- 公共 CMSIS/SPL 平台层；
- 主从应用边界；
- 可移植、版本化、带 CRC 的主从协议；
- 明确周期的主控调度器；
- 低油门启动/恢复锁和失联状态机；
- 电脑端测试、结构校验、双目标构建脚本和 CI。

## P0：飞行安全闭环

- 独立 ARM/DISARM 通道和明确 DISARM 状态；
- 解锁前传感器健康、姿态范围、电池和主从数据新鲜度检查；
- 主从链路超时策略；
- 故障原因、复位原因和 overrun 诊断；
- 无桨故障注入测试。

## P1：模块边界

- 将 PID、姿态估计和导航控制拆为纯算法模块；
- 为控制算法增加固定输入/输出接口和电脑端测试；
- 将遗留未启用驱动从默认固件目标移出；
- 建立统一参数表、范围校验、版本和持久化。

## P2：产品化

- 自托管 ARMCC CI 或迁移到可自动化的 ARM GNU 工具链；
- 静态分析、代码格式和覆盖率门槛；
- Hardware-in-the-loop 测试；
- 固件版本、构建信息、升级和回滚机制；
- 飞行日志和地面站诊断协议。
