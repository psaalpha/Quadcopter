# 架构

两颗 STM32F103C8T6 分别使用主循环与中断。主控执行飞行控制，从控执行传感器服务和显示；两端共用 CMSIS/SPL、协议和 DMA 辅助模块。

## 模块职责

| 目录 | 职责 |
|---|---|
| `Master_MCU/Core` | 启动、主循环、控制编排和中断入口 |
| `Master_MCU/App` | 周期调度与安全状态机 |
| `Master_MCU/BSP` | 时钟、定时器、电机 PWM、LED 和看门狗 |
| `Master_MCU/Control` | 姿态估计、滤波和 PID |
| `Master_MCU/Drivers` | MPU6050、软件 I2C、CRSF、蓝牙和从控链路 |
| `Slave_MCU/Core` | 启动与中断入口 |
| `Slave_MCU/App` | 传感器服务、显示和周期调度 |
| `Slave_MCU/BSP` | 板级输入、舵机、电池 ADC 和蜂鸣器 |
| `Slave_MCU/Drivers` | 传感器、主控链路、OLED 和 OSD |
| `Shared/Protocol` | 主从编解码和 CRC |
| `Shared/Scheduling` | 周期事件、合并和超期统计 |
| `Shared/Drivers` | STM32 DMA 接收和毫秒计时辅助实现 |
| `Platform/STM32F1` | CMSIS、SPL 和公共延时 |

`Shared/Protocol` 和 `Shared/Scheduling` 不访问硬件寄存器；`Shared/Drivers` 可以依赖 STM32 平台。
驱动负责设备和总线，BSP 负责板级资源；公共平台不依赖飞控业务。
Bosch BMP390 原厂文件保留上游内容与许可证。

项目自有标识符采用 `lower_snake_case`，类型使用 `_t`，宏使用 `UPPER_SNAKE_CASE`。
公开接口带模块前缀，物理量使用 `_ms`、`_mm`、`_deg`、`_dps` 等单位后缀。
中断向量及第三方接口保留原约定。

## 运行模型

TIM2 每 1ms 发布周期事件，主循环取走事件并顺序执行。周期事件积压时合并为一次执行，并增加超期计数。
任务函数执行期间产生的新事件保留到下一轮；短临界区恢复进入前的 PRIMASK。

| MCU | 工作 | 周期/触发 |
|---|---|---|
| 主控 | IMU、姿态估计、角速度内环、混控与 CCR 更新 | 2ms / 500Hz |
| 主控 | 遥控服务 | 5ms / 200Hz |
| 主控 | 角度外环 | 10ms / 100Hz |
| 主控 | 蓝牙遥测 | 100ms / 10Hz |
| 主控 | 蓝牙和主从接收解析 | 驱动事件，主循环服务 |
| 从控 | 气压、磁力计、电池与主从发布 | 50ms / 20Hz |
| 从控 | 显示快照 | 200ms / 5Hz，主循环分段输出 |
| 从控 | 光流、输入边沿与发送回收 | 驱动事件，主循环服务 |

TIM4 以 50Hz 输出四路硬件 PWM；500Hz 内环写 CCR 预装载，PWM 边界加载。
主从链路为从控 20Hz 发布、主控事件驱动接收。磁力计配置为 10Hz，仅对新有效样本置有效位。
光流按完整串口帧更新，实际模块发送频率仍待确认。

## 控制与数据路径

```text
CRSF → 遥控映射与安全状态 → 目标姿态
MPU6050 → 姿态估计 → 100Hz 角度外环 → 500Hz 角速度内环 → 混控 → 50Hz PWM
从控传感器 → 41字节协议 → 磁力计航向修正与高度/光流辅助输入
```

偏航指令积分为目标航向；磁力计新样本用于修正陀螺仪积分航向，误差采用 0/360° 最短方向。
辅助模式要求安全状态、油门和传感器数据满足门限，进入时捕获高度/光流目标。
辅助数据超过 200ms 未更新、模式退出或输入失效时清除辅助积分并回到手动目标。
高度/光流 PID 默认增益为零，光流 X/Y 为原始积分量；方向、尺度和增益仍需标定。

## 中断与主循环

- TIM2 完成硬件应答、毫秒记账和周期事件发布。
- USART/DMA RX 记录接收、回绕和错误事件，协议解析由主循环执行。
- DMA TX 记录完成/错误事件，主循环消费后释放发送缓冲。
- EXTI 记录输入边沿，主循环处理舵机、按键与校准。

PA1 舵机输入使用最终电平；PA8 校准输入保留下降/上升历史；PA0 按键在主循环去抖。
EXTI 挂起位不能恢复关中断期间的所有边沿，最短可靠输入脉宽需实测。

## DMA 与 Flash 所有权

光流 RX 使用 256B 循环缓冲，115200 baud 满线约 22.2ms 绕一圈，每轮最多处理 64B。
IDLE 表示字节间隙，HT/TC 提供连续流通知；状态机处理半帧、多帧和跨环形边界，溢出后重新同步。

主从 TX 使用独立的 41B 静态缓冲。DMA 拥有期间新请求返回 busy；完成后由主循环回收，20ms 异常超时停止并回收通道。
正常线传输约 3.56ms。DMA TC 表示缓冲可释放，USART TC 表示最后停止位已发送。

校准使用 10 秒时间窗口与有效磁场样本。保存前等待在途 TX，暂停光流 RX；保存后清除半帧并恢复接收。
从控最后 1KB Flash `0x0800FC00..0x0800FFFF` 为校准页，应用镜像上限为 63KB。
偏移先写、Magic 最后写并回读校验；当前单页方案不提供双槽掉电事务保护。

TIM2 使用 DWT CYCCNT 计算实际经过的核周期，补记 Flash 屏蔽中断期间的时间。
CYCCNT 约 59.6s 回绕，需要持续运行并频繁读取；运行期换时钟、睡眠和调试暂停不在当前计时支持范围。

## 诊断

可读取主从周期超期计数、串口 CRC/格式错误、光流溢出与重同步、主从 TX busy/错误、ADC 超时和校准保存状态。
相关接口位于各模块头文件，不在高频路径打印日志。
失联策略见[安全状态](SAFETY.md)，测试边界见[测试与验证](TESTING.md)。
